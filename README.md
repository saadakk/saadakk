## ⭐ Featured Projects

### 🔹 [Unified DevSecOps Platform](https://github.com/saadakk/unified-devsecops-platform)
**One shared DevSecOps platform for multiple projects**
Centralized GitLab CI/CD templates reused across projects, with SAST, dependency and container scanning, images stored in Harbor, all findings aggregated in DefectDojo, and deployment to AWS.
**Tech:** GitLab CI · Harbor · DefectDojo · Trivy · SonarQube · Docker · AWS

### 🔹 [Java Microservices Project](https://github.com/saadakk/java-microservices)
**Production-style microservices platform**
Spring Boot services with JWT security, REST APIs, containerized and deployed on the cloud.
**Tech:** Java 17 · Spring Boot · PostgreSQL · Docker · Kubernetes

### 🔹 [React / Angular Web App](https://github.com/saadakk/web-app)
**Modern frontend consuming secured APIs**
Responsive UI with authentication, role-based views and reusable components.
**Tech:** React · Angular · TypeScript · Tailwind CSS

### 🔹 [AWS Infrastructure as Code](https://github.com/saadakk/aws-iac)
**Reproducible cloud infrastructure**
VPC, compute and IAM defined as code with security best practices.
**Tech:** AWS · Terraform · GitLab CI
